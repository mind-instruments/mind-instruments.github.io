使用者／實驗室管理者 · Q1

如何開始使用並確認實驗室管理介面？

  1. 開啟網站，以自己的帳號登入；忘記密碼時使用登入頁的「忘記密碼」。
  2. 一般使用者從「我的實驗」查看自己的預約與持有探針。實驗室管理者按「切換管理模式」，開啟「帳號與權限」確認直屬成員。
  3. 實驗室管理者依 Q3 核准成員，依 Q4 設定儀器資格，再依 Q6 核對預約時段規則。
  4. 若需建立探針表，依 Q7–Q8 建立、上傳照片並發佈。

完成時應看到：看到與自己身分相符的個人或實驗室介面。

卡住時先檢查：若找不到所屬實驗室或管理入口，請聯絡系統負責人辦理單位及代表認證。

實驗室管理者 · Q3

如何核准直屬實驗室的一般成員？

  1. 請新成員以自己的信箱申請帳號，選擇正確實驗室。
  2. 進入「切換管理模式 → 帳號與權限」，找到該成員，按「設定權限」。
  3. 將帳號狀態設為「已核准」，依需要勾選可申請預約及可簽署已個別授權的耗材，再確認送出。
  4. 依 Q4 設定此人的儀器資格，讓成員重新整理後核對可用功能。

完成時應看到：成員的帳號已核准，且只取得指定的儀器與耗材權限。

卡住時先檢查：實驗室管理者無法自行變更角色或管理其他實驗室。代表認證、單位更動請洽系統負責人。

管理者 · Q4

如何設定每個人能使用哪些儀器？

  1. 切換管理模式 →「儀器認證」。可用姓名／信箱搜尋。
  2. 找到人員所在列、目標儀器所在欄，選擇「未認證／代工／一般／進階」。
  3. 逐格確認後按「儲存認證」，直到顯示已儲存。只改下拉選單尚未保存。
  4. 請使用者重新整理「儀器預約」，核對資格標示與可選時段。

完成時應看到：一般資格可在一般開放時段自行操作；代工資格只走代工；進階資格走自行操作並依規則開放進階時段。

卡住時先檢查：未認證不能預約。帳號已核准、可申請預約、個人儀器認證、儀器開放與時段規則都須符合。多人同時改認證出現衝突時，重載後重新核對，勿盲目覆寫。

實驗室管理者（需儀器管理權限） · Q5

如何編輯獲授權儀器的使用模式與簽退選項？

  1. 切換管理模式，進入「儀器預約」並選擇正確儀器。
  2. 開啟儀器設定；只有獲指定為該儀器管理員者才有編輯入口。
  3. 編輯使用模式或簽退狀態的名稱與要求備註選項，保留仍在使用的既有選項。
  4. 確認保存，再開啟簽退表單，核對選單已更新。

完成時應看到：該儀器的模式與狀態選單符合實際作業。

卡住時先檢查：新增儀器或變更儀器管理員請洽系統負責人；實驗室管理身分不代表所有儀器的管理權限。

管理者 · Q6

如何限制週末、晚間與延長預約的批准者？

  1. 切換管理模式 →「預約規則」，開啟修改規則。
  2. 設定一般時段開始與結束、單次上限、週末及一般時段外的開放對象。
  3. 設定「延長批准權限」為實驗室管理者或主系統管理者，確認送出。
  4. 若特定儀器要使用個別規則，到「儀器預約」選儀器 →「儀器設定」→「編輯儀器」，啟用個別規則後保存。
  5. 用一般／進階資格分別檢查週末與晚間時段；以使用者實際看到的可選格位為準。

完成時應看到：不符規則的格位顯示資格限制；延長申請交由規則指定角色處理。

卡住時先檢查：實驗室規則不能超出主系統允許的範圍；進階資格也不能繞過停機、衝突等限制。

如何確認規則真的生效：以一般成員登入 → 選儀器 → 查看週末／晚間格。若限制為進階，格子應寫「資格限制」，按下不會選取；管理者修改資格後按「重新整理」，再檢查格子與確認清單。管理者身分的豁免不能用來代表一般成員測試。

管理者 · Q7

如何加入新探針，建立數量正確的針盒表格？

  1. 切換管理模式 →「儀器預約」，先在「儀器」選單確認儀器，再按「耗材」。若會重複採購同一型號，先按「探針型號」→「＋ 建立探針型號」。
  2. 在型號表單填「型號名稱」、探針尖端 Tip、尖端半徑（nm）、鍍膜、共振頻率（kHz）、力常數（N/m）、供應商及聯絡手機。規格可填範圍，例如半徑 < 10、頻率 70–90；未提供的規格可留空。按「確認送出」。實驗室管理者建立的型號屬自己單位；中心共用型號由主系統管理者建立與維護。
  3. 按「＋ 建立針盒」，在「載入既存探針型號」選擇剛建立的型號，核對帶入的規格、供應商與手機。各欄可依這一盒實際資料調整；也可選「自行填寫」，不必先建型號。
  4. 填「針盒名稱」與「耗材型號」；編號前綴只用英文字母、數字、底線或連字號。例如名稱「OPUS 2026-11 第一盒」、前綴「OPUS2611A」。
  5. 填「實收數量」與「訂購數量」。只收到 6 支就填實收 6，不要把尚未到貨的數量當可領庫存。
  6. 先輸入數量讓系統自動排格，再視需要手動改列數／欄數；確認「格位容量」足以容納訂購數量。上限為 26 列 × 20 欄、520 支。
  7. 填單價、供應商、聯絡手機、批號、採購日期、到貨日期、儲位；補貨交期與安全庫存依需要填寫。
  8. 選針盒照片：JPEG／PNG／WebP、3 MB 內。按「確認送出」，回到針盒摘要核對名稱、數量、格位、單位與照片，展開「探針規格」確認內容。此時仍是草稿。
  9. 日後要修改型號，按「探針型號」→ 對應型號的「編輯型號」。修改只供新建針盒使用，不會改動舊盒；舊盒規格與手機請用該盒「編輯資料與照片」修改。

完成時應看到：6 支可自動排成 A1–A6；收到與訂購分開記錄，草稿尚不能讓使用者簽領。

卡住時先檢查：供應商、批號、採購日期、到貨日期和照片在發佈前都必須齊全。選「中心庫存」代表待購用途，不等於直接授權某實驗室簽領。

管理者 · Q8

如何補傳照片、設定領用權限並發佈針盒？

  1. 在「耗材」的「針盒」選單選既有草稿。若照片缺失，按「編輯資料與照片」，選有效照片，按「確認送出」。同一表單也可補填探針規格與供應商聯絡手機；舊盒原有資料會保留。
  2. 核對畫面已出現照片。若顯示資料已保存但照片尚未完成，留在同一針盒補傳；不要再按「建立針盒」。
  3. 按「批次領用權限」，勾選可領用的同實驗室成員，按「確認送出」。成員帳號仍須有「可簽署已個別授權的耗材」。
  4. 按「預覽並發佈」，核對針盒名稱、實收數量、列欄及照片，再按「確認送出」。
  5. 用一般成員帳號登入，選同一儀器與針盒，確認能看見 A1 等格位並顯示可簽署。

完成時應看到：摘要顯示「已發佈」，有授權的使用者才能簽領；未發佈的草稿不出現在一般成員清單。

卡住時先檢查：沒有照片或採購資料時，發佈會被拒絕。若照片上傳失敗，回原針盒補傳。若建立結果不明，先查原針盒是否已建立，勿立即重建。

管理者 · Q9

如何分批收貨、補針與處理損壞？

  1. 分批收貨：在針盒摘要按「登記到貨」，輸入本次新增數量與單價，確認送出。只在尚有未到貨數量時出現此按鈕。
  2. 空格或歷史位置：點格位，查看「位置歷史」；確定實際補入新針時按「補入新耗材」，填永久編號與價格。
  3. 使用者回報損壞後，管理者點該格位，查看待檢狀態，按「檢查處理」依實物情況處置。
  4. 調撥用「盤點／調撥」並填原因、相同型號與儀器的目的針盒及空格。送出前核對目的單位與實際位置。

完成時應看到：舊針的領用歷史保留，不藉由新增一盒掩蓋損耗。

卡住時先檢查：不能把同一支針同時放在兩格；已領用的針要先處理實際持有狀態。沒有管理權限的使用者不能執行盤點。

管理者 · Q10

如何核准或退回使用者預約？

  1. 使用實驗室管理者登入，切換管理模式 →「申請審核」。
  2. 逐筆核對申請者、實驗室、儀器、起訖時間、預約方式與量測內容。
  3. 按「核准」，閱讀責任與紀錄提示，再按「確認送出」。要退回則按「不核准」，依畫面填說明。
  4. 請使用者重新整理「我的實驗」，確認狀態從「待審核」變為「已預約」，並出現負責管理者。

完成時應看到：待審項目消失；核准者與時間保存在系統。

卡住時先檢查：待審不代表時段已保留。核准時若資格撤銷、已衝突或庫存不符，會被拒絕，應重新安排；不要反覆按核准。

管理者 · Q11

如何停用帳號、再恢復使用？

  1. 管理模式 →「帳號與權限」→ 目標成員「設定權限」。
  2. 確認不是同名的其他人，將帳號狀態改成「已停用」，確認送出。
  3. 恢復時改為「已核准」，再核對預約／領用開關與儀器認證。
  4. 檢查該成員未完成的預約與持有耗材，依實際情況處理；不要把停用視為已完成歸還或簽退。

完成時應看到：新操作受現行帳號狀態限制，已開頁面不能繞過系統檢查。

卡住時先檢查：實驗室管理者只能處理其權限範圍內的一般成員。

如何處理已開啟的舊表單：停用不會自動替本人取消全部既有工作。舊預覽送出會被系統重新檢查；若出現未確認操作，按「檢查／重試」取得確定結果。停用者仍可完成自己的歸還或取消收尾，不能新增預約。

管理者 · Q13

如何交接管理職務與過往紀錄？

  1. 接任者先建立自己的獨立帳號並取得適當帳號狀態。管理模式 →「帳戶繼承」。
  2. 建立交接，依情境選個人職務與工作交接或實驗室帳戶接任，指定原負責人與接任者並填原因。
  3. 核對要交接的未來預約與實際交付耗材，只勾選應承接的項目。
  4. 接任者到「我的帳戶」確認接任；需要主系統認證時由主系統管理者認證接任者。狀態可完成後再按「完成交接」。
  5. 從「承接歷史紀錄」核對授予的歷史範圍，並另行核對接任者儀器資格。固定帳戶可用「歷任紀錄」查看過去的原始紀錄；接任不會把原操作者改成現任持有人。

完成時應看到：原始操作者姓名保留；接任者取得明確授權的工作與歷史。

卡住時先檢查：不複製密碼、個人 Google 授權或儀器資格；尚未確認／認證不等於交接完成。

管理者 · Q14

如何查看使用量、費用與庫存趨勢？

  1. 切換管理模式 →「分析圖表」。
  2. 選近 30／90／180 天或自訂期間，再選儀器與實驗室；實驗室管理者只查看自己的單位。
  3. 按「更新分析」，核對更新時間及篩選條件後閱讀使用量、空閒、費用與耗材分析。
  4. 切換「耗材與預測」，選擇趨勢圖型號，核對首次領用量、目前庫存與資料不足提示；回到「儀器分析」查看時數與收益。

完成時應看到：分析不改寫原始資料；資料不足時不硬算耗盡日期。

卡住時先檢查：收益是費用估算而非實際收款；缺費率、未簽退或開放歷史不足會降低精度。預測不含未來補貨，不能作為保證日期。

如何設定儀器認證效期並辦理續證？

完成時應看到：到期、尚未生效或停權者無法成為有效操作員；續證後可重新提出安排。

卡住時先檢查：實驗室管理者只可調整直屬的一般成員；不能藉續證提升自己的資格或其他實驗室成員。

管理者 · Q33

卡住時先檢查：沒有候選人時會顯示資格與效期提示，不能送出空操作員。選單不等於保證所有排程條件可用；接任時仍重新檢查衝突。一般實驗室管理者只能從其可見成員中安排。

管理者 · Q44

如何處理未到場或前一場未簽退，讓儀器安全釋放？

  2. 未簽到的已預約場次：管理模式開預約詳情，使用「確認儀器未使用」，填現場確認原因。

完成時應看到：管理者確認釋放後會取消該場次待審延長；保存原簽到紀錄及管理者處理紀錄。

卡住時先檢查：異常仍需報修；確認釋放不代表把故障儀器恢復可用。現場確認權限與一般成員操作權不同。

如何確認自動釋放已完成：確認未使用後，等待下一次排程檢查並重新整理；應看到「已釋放」。雲端排程每分鐘檢查，網站請求也會補做檢查；外部服務延遲時可能稍晚，詳見 Q70。若仍已預約，先核對未到延遲是否啟用、是否已過門檻及是否確實保存現場確認。

使用者 · Q46

如何從 CSV 或 ICS 匯入預約，避免時區與重複資料錯誤？

  1. 到「預約協作」→「預約待辦」→「匯入行程」，選目標儀器。
  2. 選 CSV 或 iCalendar (.ics)，無時區資料的解讀時區一般填 Asia/Taipei；選檔或貼上內容。
  3. CSV 欄位為 start,end,purpose,source_uid。每筆 start/end 使用明確日期時間及時區；source_uid 保持穩定以辨識重複。

  5. 匯入一律先送審，管理者匯入也不是自動核准；到清單確認結果。

完成時應看到：最多 50 筆、檔案與內容限約 50,000 bytes／字元入口限制；錯誤行會明示，不會默默改成另一時段。

卡住時先檢查：帶週期規則的 ICS 必須先展開場次，不能只匯入第一筆。夏令時間有歧義時需先明確指定時間。匯出的分析 CSV 欄位和匯入格式不同，不可直接當作還原檔。

CSV 先帶 start,end,purpose,source_uid 標頭，時間可寫 2026-11-24T09:00:00+08:00；ICS 使用 Z 表示 UTC。重複來源顯示錯誤時，原表單仍保留，不必另建同一場。

如何安全換檔及處理讀取錯誤：選檔後先看內容與格式，再預覽。讀取中不能送出；超過 50,000 bytes 或讀取失敗時，舊內容會清空並顯示錯誤。重新選有效檔或貼上內容即可重試，不必關閉重建。時間可用 2026-11-23T01:00:00.000Z 或明確 +08:00；無時區才使用所選時區。

  5. 確定要修改時重新開啟「日期例外」，重新填完整設定，重新預覽後送出。不要反覆點舊視窗的確認。

完成時應看到：舊預覽不會覆蓋較新的日期規則；不同日期的正常操作不會無故互相阻擋。

卡住時先檢查：目前錯誤提示統一使用「預約狀態」，也涵蓋日期規則變更。預覽不會鎖住當日設定或保留時段；最終提交仍重新檢查。

管理者 · Q65

如何安全移除日期例外，恢復一般預約規則？

  3. 按「移除例外」，填寫處理原因，按「確認送出」。
  4. 如果顯示「預約已改變，請重新整理後再申請」，可能是其他管理者更新了同一例外。關閉視窗、重新整理，閱讀最新原因後再決定。
  5. 確認最新規則確實能移除時，從最新卡片重新按移除，填原因並送出；成功後該有效例外卡片消失。再到儀器日曆核對一般規則下的可預約狀態。

完成時應看到：舊視窗不能移除新版本的例外；成功移除保留原規則與處理紀錄，不抹掉歷史。

卡住時先檢查：移除休館不代表全部時間都開放；仍受一般規則、儀器狀態、維修、個人資格及既有預約限制。

管理者／使用者 · Q66

如何在新增必備配件後，確認舊預約不會和其他儀器搶同一配件？

  1. 先請系統負責人建立共用配件，並確認適用儀器。
  2. 在需要此配件的儀器卡按「排程規則」，勾選「必要配件」，先預覽受影響預約再確認。這不會批次重寫所有舊預約；管理者應查看影響清單並協調尚未確認配件的安排。
  3. 舊預約之後審核、維修改期、延長核准或簽到時，系統會再次檢查當時的必要配件，成功才把占用保存在該筆預約。延長仍遵守設定的批准權限。
  4. 在另一儀器建立預約時，需用共用配件就勾「聯訂配件」對應項目，再填量測內容並送出；日曆儀器格可選，不代表每一件選配配件都有空。
  5. 若顯示「聯訂配件已在此時段被占用」，原表單會保留，這次未新增預約；關閉後改選可用時段，或聯繫管理者協調。請勿為了通過而取消真正需要的配件。
  6. 簽到或延長遇到配件衝突時，該操作不會只完成一半；先解決衝突，重新確認預約狀態後再處理。

完成時應看到：成功確認的預約持有需要的配件；同一配件不能被兩台儀器在重疊時段重複取得，重啟後仍保留占用。

卡住時先檢查：「必要配件」不同於探針耗材的領用或簽署。舊預約尚未重新確認前的配件協調仍需管理者處理，本次未新增批次占用或自動取消既有預約。

管理者／已獲授權的使用者 · Q77

如何補登過往儀器使用、探針購買及領用紀錄？

  1. 需先取得歷史補登權限。正式模式匯入的紀錄會成為正式資料；若只是練習，請先洽系統負責人安排隔離測試。
  2. 開啟左側「歷史補登」。選擇範例帳戶、儀器及針盒，按「下載匯入範例」。範例填有既存實驗室、帳戶、儀器、針盒與探針的 ID 和標籤。每份最多涵蓋 99 支探針；更大針盒可從第 100、199 支接續下載。
  3. 用試算表開啟 CSV，把 ID、日期及代號欄保留為文字。刪除不需要的範例列；每筆 source_id 填唯一的英數代號，可加底線或連字號。請用真實紀錄取代範例日期，不要直接把範例當作正式歷史。
  4. type 填 booking 表示已完成儀器使用、purchase 表示單支探針購買、usage 表示已結束探針領用。booking 的 amount 是每小時費率；purchase 是單支購買金額；usage 留空。只有確定免費時填 0；不知道金額時請先查明，不要用 0 代替未知費用。
  5. start、end 使用含時區格式，例如 2026-01-15T09:00:00+08:00。booking／usage 都要填起訖時間，儀器使用單筆最多 24 小時，結束不得晚於現在；purchase 只填購買時間 start。探針可填跨日的真實領用與歸還時間。
  6. 探針紀錄須使用既存 box_id 及 probe_id，且探針須屬於指定針盒、儀器與實驗室。針盒必須已發佈（Q7–Q8）；不存在時整批匯入失敗，不會自動新增針盒。label 欄若填寫，須和該 ID 的目前名稱一致。購買紀錄已存在的探針，不要再填一次 purchase。
  7. 儀器使用的 mode／condition 請填頁面列出的代號。探針 condition 可填 good（良好）、worn（磨耗）、contaminated（污染）或 damaged（損壞）。另存「CSV UTF-8」，每批最多 200 筆、200 KB。
  8. 填寫補登原因、上傳 CSV，再按「檢查匯入資料」。若有列號及錯誤，先修正原檔再上傳；任何一列有錯，整批不寫入。全部通過後按「確認補登」，核對新增與略過筆數。
  9. 管理者進入「分析圖表」，將日期範圍設為包含歷史日期，再按「更新分析」，核對使用時數、收益估算與耗材用量。收益是估算，並不代表已收到款項。
  10. 選擇「匯出批次」，按「匯出補登紀錄」可下載相同欄位格式；資料多時會依 200 筆與 200 KB 上限自動分批，請逐批下載。原檔重匯相同 source_id 與內容會略過，不重複計費。成員改名或轉單位後，具原歷史範圍權限的管理者仍可重匯原檔；新補登資料則必須符合目前帳戶與實驗室對應。相同 source_id 但內容改變會拒絕；若需修正既有出勤或費用，使用原有補登／費用更正流程。

完成時應看到：完成紀錄保留實際日期、補登者與原因，圖表依歷史日期計算。匯出檔可原格式重匯。

卡住時先檢查：此功能補入歷史，不改變目前探針持有人及實物狀態，也不建立過期 Google 事件或寄漏簽提醒。單支探針的重複使用次數不等於消耗多支庫存；庫存預測依首次使用計算。一般成員無權查看管理圖表，請由管理者核對。
