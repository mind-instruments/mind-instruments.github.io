隱私權與 Google 資料使用

更新日期：2026-11-16

資料與用途

本站用於儀器預約、出勤、耗材領用、實驗室審核及紀錄交接。處理帳號姓名、電子郵件、所屬實驗室、角色與儀器資格，以及使用者提交的預約、出勤、耗材、附件與操作紀錄。管理者依本站角色及實驗室權限查看資料。

Google 授權

連結 Google 為獨立選項。本站取得已驗證的電子郵件地址、Google 帳戶識別碼，以及供背景工作使用的授權憑證。

  • 個人日曆：要求 calendar.app.created 權限，建立「CNMM 儀器預約」次要日曆，在該日曆建立、修改或取消本人已核准的預約活動。活動包含儀器名稱、預約識別碼、開始與結束時間。此整合不要求讀取主要日曆或既有私人日曆。
  • 寄件帳號：僅主系統管理者可連結，要求 gmail.send 權限，代表授權信箱寄出預約通知、帳戶復原信及漏簽提醒。寄送時，收件地址、主旨及通知內容會傳送至 Google Gmail。此整合不要求讀取信件、收件匣或通訊錄。

儲存、服務與使用範圍

網站由 GitHub Pages 託管，後臺及資料儲存使用 Supabase；日曆與寄信由 Google 提供。上述服務處理履行其功能所需的資料。登入憑證僅暫存在目前瀏覽器分頁，關閉分頁後移除；密碼以雜湊形式保存，Google 更新權杖在後臺加密保存，不提供給網頁。Google 資料僅用於帳戶識別及使用者要求的日曆與通知功能，不用於廣告、出售或訓練通用 AI 模型。

本站使用及轉移 Google API 資料，遵循 Google API Services User Data Policy，包括 Limited Use 要求。

解除連結與紀錄保存

使用者可在「我的帳戶」解除個人日曆連結；主系統管理者可停用寄件帳號。解除後本站停止使用對應授權，並向 Google 請求撤銷。也可在 Google 帳戶的第三方連線移除存取權。同一 Google 應用程式的撤銷可能影響另一項授權，必要時請重新連結仍需使用的功能。

解除連結不會刪除既有 Google 日曆或本站的預約、出勤、耗材及稽核紀錄。已送出的郵件仍由寄件與收件服務保存。若需更正、匯出或刪除資料，請透過所屬實驗室管理者聯絡主系統管理者，確認權限、紀錄保存需求與備份處理範圍。

English summary

CNMM processes account, laboratory, certification, booking, attendance, consumable, attachment and audit information to operate this booking service. Access follows application roles and laboratory permissions. Hosting and storage use GitHub Pages and Supabase.

Optional Google connections use verified email and account identity. The calendar.app.created scope creates and manages a dedicated secondary booking calendar. The gmail.send scope lets an authorized system administrator's mailbox send service notifications; it does not grant access to inbox contents or contacts. Google refresh tokens are encrypted on the backend. Google data is used only for these features, not advertising, sale or training general-purpose AI models. Use and transfer comply with Google's API Services User Data Policy, including Limited Use requirements.

Disconnect in My account or revoke access in Google Account connections. Existing booking history, calendar events and delivered messages are not automatically deleted. Contact your laboratory or system administrator for data access, correction, export and deletion requests.
